01

Über Doppelcheck

Was es ist und warum es existiert.

Online-Texte wirken vertrauenswürdig, weil sie wie Texte aussehen. Welche Aussagen darin sind tatsächlich belegt, welche zitieren ältere Behauptungen, welche stehen gegen Faktenchecks oder unabhängige Quellen? Diese Fragen kostet jede einzelne Recherche Zeit, Konzentration und Routine.

Doppelcheck nimmt diese Routine ab. Es ist eine Browser-Erweiterung, die parallel zum Lesen die tragenden Behauptungen eines Artikels herauszieht, sie gegen Faktencheck-Datenbanken und unabhängige Quellen spiegelt — und Übereinstimmungen wie Widersprüche direkt am Text sichtbar macht. Inhalte verlassen das Gerät standardmäßig nicht.

„Kritisch lesen heißt nicht misstrauen — es heißt prüfen können."

02

Funktionen

Was die Erweiterung im Alltag tut.

📋

Behauptungen extrahieren

Identifiziert automatisch die tragenden Faktenaussagen eines Artikels.

🔍

Belege finden

Sucht Faktenchecks und unabhängige Quellen zu jeder einzelnen Behauptung.

⚖️

Vergleichen

Stellt Übereinstimmungen, Widersprüche und Lücken zwischen Artikel und Quellen dar.

🖌️

Direkt im Artikel

Hebt Behauptung und Belegstellen farbig direkt im Originaltext hervor.

⚙️

Eigene Quellen

Hinterlegen Sie Domains, denen Sie vertrauen — Doppelcheck sucht zuerst dort.

🔒

Privat by default

Im Standardpfad bleibt der Inhalt auf dem Gerät. Kein Drittserver, keine Konten.

03

Installation

In drei Schritten einsatzbereit.

  1. 1

    Erweiterung laden

    Bauen Sie die Erweiterung aus dem Quelltext und laden Sie sie als entpacktes Add-on. Unterstützt: Chrome, Edge, Brave, Arc, Opera, Firefox 128+.

    Anleitung auf GitHub ↗
  2. 2

    API-Schlüssel eintragen

    Ein kostenloser Brave-Search-API-Schlüssel reicht für den persönlichen Gebrauch. Optional: ein Google-Fact-Check-Schlüssel für bestehende Faktenchecks.

    Brave-Schlüssel anfordern ↗
  3. 3

    Sprachmodell wählen

    Standard ist Chromes integriertes Modell — kostenlos und auf dem Gerät. Alternativ: ein Cloud-Anbieter Ihrer Wahl oder ein lokaler Server.

    Optionen ansehen ↓

Alle Einstellungen leben auf dem Gerät und synchronisieren über den Browser. Vollständige technische Einrichtung im Entwickler-Bereich.

04

Häufige Fragen

Was Nutzer regelmäßig fragen.

  • Verlassen meine Inhalte das Gerät? +

    Im Standardpfad nicht. Mit Chromes browser-internem Modell läuft die Sprachverarbeitung auf dem Gerät. Wenn Sie eine Cloud-API wählen, gehen Anfragen direkt an diesen Anbieter — Doppelcheck proxiet nichts. Quellensuche und das Laden externer Belege gehen naturgemäß ins offene Web.

  • Welche Browser werden unterstützt? +

    Chromium-basierte Browser (Chrome, Edge, Brave, Arc, Opera) auf Windows / macOS / Linux / ChromeOS und Firefox 128+. Mobile Browser sind aktuell nicht unterstützt.

  • Was kostet die Nutzung? +

    Die Erweiterung ist Open Source und kostenlos. Brave Search bietet einen kostenlosen Tarif (~1.000 Anfragen pro Monat — für persönlichen Gebrauch reichlich). Wer einen Cloud-Anbieter für das Sprachmodell wählt, zahlt direkt an diesen Anbieter.

  • Kann ich vertrauenswürdige Quellen festlegen? +

    Ja. In den Optionen tragen Sie Domains ein, denen Sie vertrauen. Brave Search führt zusätzlich zur allgemeinen Suche pro Domain eine eingegrenzte Anfrage aus.

Für Entwickler

Technische Einrichtung

Aus dem Quelltext bauen, Modell-Stufen wählen, lokal hosten. Vollständige Dokumentation in den Repositorien.

Aus dem Quelltext bauen

$ git clone https://github.com/doppelcheck/main doppelcheck
$ cd doppelcheck
$ npm install
$ npm run build           # → .output/chrome-mv3/
$ npm run build:firefox   # → .output/firefox-mv2/

Anschließend in chrome://extensions oder about:debugging als entpackte Erweiterung laden.

Drei LLM-Stufen

  • Browser-intern — Chromes Gemini Nano via Prompt-API. Standard. Kostenlos, on-device. Chrome 138+.
  • Cloud-API — Anthropic Claude (claude-haiku-4-5 empfohlen), OpenAI oder Google Gemini. Eigener Schlüssel.
  • Lokaler Server — Ollama oder OpenAI-kompatibel. Voll-lokaler Pfad: das Begleit-Repo gemma-server.

Lokales Modell — gemma-server

Konfigurationsfreier lokaler Gemma-Server für Doppelcheck. Vom Klonen bis zum Endpoint auf localhost:11434 in einem Befehl.

$ git clone https://github.com/doppelcheck/gemma-server
$ cd gemma-server
$ ./start.sh           # or: docker compose up

Doppelcheck liest mit, isoliert die tragenden Behauptungen eines Artikels und prüft sie gegen Faktenchecks und unabhängige Quellen — direkt am Text, auf Ihrem Gerät.

Was Doppelcheck ist

Online-Texte wirken vertrauenswürdig, weil sie wie Texte aussehen. Welche Aussagen darin sind tatsächlich belegt, welche zitieren ältere Behauptungen, welche stehen gegen Faktenchecks oder unabhängige Quellen? Diese Fragen kostet jede einzelne Recherche Zeit, Konzentration und Routine.

Doppelcheck nimmt diese Routine ab. Es liest parallel mit, zieht die tragenden Behauptungen heraus, spiegelt sie an Faktencheck-Datenbanken und unabhängigen Quellen und macht Übereinstimmung wie Widerspruch direkt am Text sichtbar. Inhalte verlassen das Gerät standardmäßig nicht.

Erklärvideo — ca. 2 Min.

So liest Doppelcheck mit

Eine kleine Demonstration. Der folgende Absatz ist ein Beispielartikel — die Markierungen zeigen, was Doppelcheck im Browser daraus macht.

https://example.com/artikel/2026-05-05 Beispielartikel

Eine neue Studie behauptet, Kaffee senke das Risiko für Herz-Kreislauf-Erkrankungen um 30 %. Der Bericht beruft sich auf eine Auswertung skandinavischer Kohorten, die über zwei Jahrzehnte mehr als 200.000 Teilnehmer beobachtet haben sollen. Befürworter sehen darin einen Beweis, dass moderater Konsum gesundheitlich unbedenklich sei.

◆ Doppelcheck
  • 1 Kaffee senke das Risiko um 30 % 2 Quellen stimmen zu
  • 2 200.000 Teilnehmer · 20 Jahre Quelle: 175.000
  • 3 Moderat = unbedenklich 3 Quellen widersprechen

Klick auf eine Markierung im Browser öffnet die jeweilige Quelle. Hier nur zur Veranschaulichung.

Was es tut

  • 📋

    Behauptungen extrahieren

    Identifiziert die tragenden Faktenaussagen eines Artikels — in der Sprache des Originals.

  • 🔍

    Belege finden

    Sucht zunächst in Faktencheck-Datenbanken, danach im offenen Web nach unabhängigen Quellen.

  • ⚖️

    Vergleichen

    Stellt Übereinstimmungen, Widersprüche und Lücken zwischen Artikel und Quellen dar.

  • 🖌️

    Direkt im Artikel

    Markiert Behauptung und Belegstellen am Originaltext — ohne das DOM zu verändern.

  • ⚙️

    Eigene Quellen

    Hinterlegen Sie Domains, denen Sie vertrauen — Doppelcheck sucht zuerst dort.

  • 🔒

    Privat by default

    Im Standardpfad bleibt der Inhalt auf dem Gerät. Kein Drittserver, keine Konten.

Fragen & Antworten

  • Verlassen meine Inhalte das Gerät? +

    Im Standardpfad nicht. Mit Chromes browser-internem Modell läuft die Sprachverarbeitung auf dem Gerät. Wenn Sie eine Cloud-API wählen, gehen Anfragen direkt an diesen Anbieter — Doppelcheck proxiet nichts. Quellensuche und das Laden externer Belege gehen naturgemäß ins offene Web.

  • Welche Browser werden unterstützt? +

    Chromium-basierte Browser (Chrome, Edge, Brave, Arc, Opera) auf Windows / macOS / Linux / ChromeOS und Firefox 128+. Mobile Browser sind aktuell nicht unterstützt.

  • Was kostet die Nutzung? +

    Die Erweiterung ist Open Source und kostenlos. Brave Search bietet einen kostenlosen Tarif (~1.000 Anfragen pro Monat — für persönlichen Gebrauch reichlich). Wer einen Cloud-Anbieter für das Sprachmodell wählt, zahlt direkt an diesen Anbieter.

  • Kann ich vertrauenswürdige Quellen festlegen? +

    Ja. In den Optionen tragen Sie Domains ein, denen Sie vertrauen. Brave Search führt zusätzlich zur allgemeinen Suche pro Domain eine eingegrenzte Anfrage aus.

Für Entwickler

Technische Einrichtung

Quelltext, Modell-Stufen, lokal hosten. Vollständige Dokumentation in den Repositorien.

Aus dem Quelltext bauen

$ git clone https://github.com/doppelcheck/main doppelcheck
$ cd doppelcheck
$ npm install
$ npm run build           # → .output/chrome-mv3/
$ npm run build:firefox   # → .output/firefox-mv2/

Anschließend in chrome://extensions oder about:debugging als entpackte Erweiterung laden.

Drei LLM-Stufen

Browser-intern
Chromes Gemini Nano via Prompt-API. Standard. Kostenlos, on-device. Chrome 138+.
Cloud-API
Anthropic Claude (claude-haiku-4-5 empfohlen), OpenAI oder Google Gemini. Eigener Schlüssel.
Lokaler Server
Ollama oder OpenAI-kompatibel. Voll-lokaler Pfad: das Begleit-Repo gemma-server.

Lokales Modell — gemma-server

Konfigurationsfreier lokaler Gemma-Server. Vom Klonen bis zum Endpoint auf localhost:11434 in einem Befehl.

$ git clone https://github.com/doppelcheck/gemma-server
$ cd gemma-server
$ ./start.sh           # or: docker compose up
